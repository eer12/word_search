# 文档本地存储检索系统1.2

## 系统介绍

**文档本地存储检索系统1.2** 是一个专业的本地文档管理和检索工具，旨在帮助用户更高效地管理和查找本地文档。

### 核心功能

- **多格式支持**：支持Word、PDF、WPS等多种文档格式（pdf文件目前未接入ocr识别功能，仅支持pdf标准件）
- **智能检索**：自动提取文档内容并建立索引，支持关键词搜索
- **分类管理**：灵活的文档分类系统，支持多分类标签
- **文件操作**：支持在线预览、下载和打开文件位置
- **自定义设置**：可配置上传目录和其他系统参数

## 快速开始

### 环境要求

- Python 3.6 或更高版本
- 依赖库：Flask、PyPDF2、python-docx、pytesseract（可选，用于OCR）

### 安装步骤

1. **克隆或下载**本项目到本地目录
2. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   ```
3. **启动系统**：
   ```bash
   python app.py
   ```
4. **访问系统**：在浏览器中打开 `http://127.0.0.1:3000`

## 使用指南

### 1. 上传文档

- 点击导航栏的"上传文档"
- 选择要上传的文档文件
- 选择分类标签（可多选）
- 填写发文单位和备注信息
- 点击"上传文档"按钮

### 2. 文档检索

- 点击导航栏的"文档检索"
- 输入搜索关键词
- 选择分类（可选）
- 点击"搜索"按钮
- 查看搜索结果和关键词上下文

### 3. 分类管理

- 点击导航栏的"分类管理"
- 点击"添加分类"创建新分类
- 点击"编辑"修改现有分类
- 点击"删除"移除不需要的分类

### 4. 系统设置

- 点击导航栏的"系统设置"
- 修改上传目录路径
- 点击"保存设置"应用更改

## 系统配置

### 配置文件

系统配置位于 `config.py` 文件中：

```python
class Config:
    # 默认上传目录
    UPLOAD_FOLDER = r'F:\backup'
    # 允许的文件类型
    ALLOWED_EXTENSIONS = {'docx', 'pdf', 'doc', 'wps'}
    # MySQL数据库配置
    DB_CONFIG = {
        'host': 'localhost',
        'user': 'root',
        'password': '123456',
        'database': 'document_search'
    }
```

### 数据库

系统默认使用SQLite数据库，也支持MySQL（如果可用）。

- SQLite数据库文件：`documents.db`
- MySQL数据库：`document_search`

## 常见问题

### 1. 上传失败

- **原因**：文件格式不支持或文件过大
- **解决**：确保上传文件为支持的格式，文件大小建议不超过100MB

### 2. 搜索无结果

- **原因**：关键词拼写错误或文档未被索引
- **解决**：检查关键词拼写，确保文档已成功上传

### 3. 无法预览文档

- **原因**：文档格式不支持在线预览或文件损坏
- **解决**：尝试下载后本地打开

### 4. 上传目录权限

- **注意**：设置的上传目录需要有写入权限
- **建议**：使用绝对路径，如 `D:\Documents\uploads`
